# 📄 XML Viewer

TypeScriptで作成した、XMLファイルをドラッグ&ドロップでプレビューできるWebアプリケーションです。

## ✨ 特徴

- 🎯 **ドラッグ&ドロップ対応** - XMLファイルを簡単にドロップしてプレビュー
- 📋 **帳票プレビュー** - XMLデータを美しい帳票・フォーム形式で表示
- 📊 **テーブル表示** - Excel風のスプレッドシート形式で繰り返しデータを可視化
- 🌳 **ツリー表示** - XMLの階層構造を見やすく表示
- 📝 **Raw表示** - 整形されたXMLテキストを表示
- 🖨️ **印刷対応** - 帳票プレビューから直接印刷可能
- 🎨 **モダンなUI** - 美しいグラデーションとアニメーション
- 📋 **コピー機能** - ワンクリックでクリップボードにコピー
- 💾 **ダウンロード機能** - 表示中のXMLファイルを再ダウンロード
- 📱 **レスポンシブ対応** - スマートフォンでも快適に使用可能

## 🚀 使い方

### 1. 依存関係のインストール

```bash
npm install
```

### 2. TypeScriptのビルド

```bash
npm run build
```

### 3. アプリケーションの起動

```bash
npm run dev
```

ブラウザが自動的に開き、`http://localhost:8080` でアプリケーションが表示されます。

### 4. XMLファイルの読み込み

以下の2つの方法でXMLファイルを読み込めます：

1. **ドラッグ&ドロップ** - XMLファイルをブラウザのドロップゾーンにドロップ
2. **ファイル選択** - 「ファイルを選択」ボタンをクリックしてファイルを選択

### サンプルXMLファイル

プロジェクトには3つのサンプルXMLファイルが含まれています：

- **sample.xml** - 書籍カタログのデータ
- **sample-employees.xml** - 従業員情報のデータ（テーブル表示に最適）
- **sample-products.xml** - 商品と注文のデータ（テーブル表示に最適）

テーブル表示機能を試すには、`sample-employees.xml`または`sample-products.xml`を読み込んでください！

## 📖 主な機能の説明

### 帳票プレビュー

XMLデータを実際の書類レイアウトで表示します。

- **自動レイアウト**: XMLの構造を解析して適切な帳票レイアウトを生成
- **印刷対応**: 「🖨️ 印刷」ボタンで直接印刷可能
- **罫線付き表**: データを見やすい表形式で表示
- **フォーム形式**: フィールドをグリッドレイアウトで配置
- **テンプレート選択**: 複数の表示テンプレートから選択可能

### テーブル表示（Excel風）

XMLの繰り返しデータを自動的に検出し、スプレッドシート形式のテーブルで表示します。

- **自動データ抽出**: 同じタグ名の繰り返し要素をテーブルとして認識
- **Excel風デザイン**: グリッドライン、行番号、ホバーエフェクト
- **スティッキーヘッダー**: スクロール時もヘッダーが常に表示
- **属性サポート**: XML属性も列として表示（@プレフィックス付き）
- **ネストデータ**: 入れ子構造のデータもJSON形式で表示

### ツリー表示

XMLの要素を階層構造で表示します。各ノードは折りたたみ可能で、以下の情報を表示します：

- 要素名
- 属性とその値
- テキストコンテンツ
- コメント

### Raw表示

整形されたXMLテキストを表示します。シンタックスハイライトはありませんが、読みやすくインデントされています。

### コピー機能

現在表示中のXMLコンテンツをクリップボードにコピーできます。

### ダウンロード機能

表示中のXMLファイルを再ダウンロードできます。

## 🎨 カスタマイズ

### スタイルの変更

`styles.css` ファイルの `:root` セクションでカラーテーマを変更できます：

```css
:root {
    --primary-color: #3b82f6;
    --primary-hover: #2563eb;
    --success-color: #10b981;
    --danger-color: #ef4444;
    /* ... その他のカラー変数 */
}
```
